# Plan Mode

Use this skill when the user wants an implementation plan instead of immediate execution.

## Core behavior

- Understand the request before changing code.
- Break work into explicit steps, risks, and verification.
- Ask for clarification when a requirement is underspecified.
- Keep the plan concrete enough to execute without rediscovery.

## Output requirements

When planning code work, include:
- goals and assumptions
- files likely to change
- validation steps
- open questions or tradeoffs

Do not claim work is done until the implementation and verification actually happen.
