# Web Research

Use this skill when you need current information from the web.

## Core behavior

- Search before extracting pages.
- Prefer authoritative documentation and primary sources.
- Summarize findings with source links.
- Keep fetched content focused on the question being answered.

## Working style

Use search results to choose the best pages, then extract only the details that matter for the task.
